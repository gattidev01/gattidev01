## Java e Spring Boot — código verificável

### [Orçamentos API](https://github.com/gattidev01/api-simples)

[![CI](https://github.com/gattidev01/java-orcamentos-api/actions/workflows/ci.yml/badge.svg)](https://github.com/gattidev01/java-orcamentos-api/actions/workflows/ci.yml)

API REST criada a partir de um domínio que conheço: gestão de orçamentos para oficinas.

- Java 21 e Spring Boot 4
- Spring Security com autenticação JWT
- Spring Data JPA, PostgreSQL e migrações Flyway
- validação, paginação e tratamento padronizado de erros
- autorização por proprietário do recurso
- testes com JUnit, AssertJ e Mockito
- CI com GitHub Actions

O README do projeto explica as decisões técnicas, arquitetura, endpoints e como executar localmente.
